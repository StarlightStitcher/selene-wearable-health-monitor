# Sensor Drivers

This directory contains the MicroPython drivers used to interface with SELENE's physiological and environmental sensors.

## Sensors

- MAX30102 — Photoplethysmography (PPG) sensing
- MAX30205 — Temperature measurement
- VEML7700 — Ambient light sensing for contact detection

All sensors communicate with the Raspberry Pi Pico 2 W through the I²C interface.
